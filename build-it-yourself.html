The challenge

Tap the money bag!

You are the whole Makinka Sky Squad: Emmanuel, Nduwa, Jemimah, and Joshua. A money bag jumps around the screen. Tap it as many times as you can before the 15-second timer runs out.

This tiny game has a real score, a real timer, random movement, and a Play Again button. Everything fits in 14 lines.

🎯 The rule: make one change at a time, save, refresh, and test. That is how real coders learn.

Before you type

You need

  • Chrome, Edge, Firefox, or Safari
  • About half an hour and a sense of adventure

The whole game

Type these 14 lines

The first line is long because the 15-line limit is strict. Keep it on one line. Type it into a new file; do not use Microsoft Word.

HTML · your game · 14 lines 
<!doctype html><html><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width,initial-scale=1"><title>Makinka Money Pop</title></head>
<body style="margin:0;min-height:100vh;text-align:center;font-family:sans-serif;background:linear-gradient(#bfe8ff,#fff3c4);color:#10243e">
<h1 style="margin:18px 0 4px;color:#10243e">Makinka Money Pop 💰</h1>
<p style="margin:0 10px;font-weight:bold">Tap the money bag! 🦊 Emmanuel · 🐼 Nduwa · 🐰 Jemimah · 🐻 Joshua · in their SR-71 🛩️</p>
<h2 style="margin:12px"><span id="s">0</span> coins · <span id="t">15</span> seconds</h2>
<button id="b" onclick="hit()" style="position:absolute;left:50%;top:60%;transform:translate(-50%,-50%);border:0;background:none;font-size:76px;cursor:pointer;filter:drop-shadow(0 8px 6px rgba(0,0,0,.2))">💰</button>
<button onclick="location.reload()" style="position:absolute;left:50%;bottom:18px;transform:translateX(-50%);padding:10px 18px;border:0;border-radius:999px;background:#ffb703;color:#10243e;font-size:16px;font-weight:bold;box-shadow:0 4px 0 #d18a00">Play Again</button>
<script>
let s = 0, t = 15, b = document.getElementById("b"), T;
function move() { b.style.left = Math.random() * 70 + 15 + "%"; b.style.top = Math.random() * 45 + 30 + "%"; }
function hit() { s++; document.getElementById("s").textContent = s; move(); }
move();
T = setInterval(function () { document.getElementById("t").textContent = --t; if (t === 0) { clearInterval(T); b.disabled = true; b.textContent = "🏆 " + s; document.querySelector("h2").textContent = "Time's up! You scored " + s + " coins."; } }, 1000);
</script></body></html>

💡 Why is line 1 so long?

Line 1 does several setup jobs: it tells the browser this is an HTML page, adds the phone-friendly viewport, and sets the tab title. We packed it in to stay under 15 lines. That is a real coding trade-off: short code can be harder to read. In a bigger game we would give each part its own line.

Save it

  1. Open Notepad (or another plain-text editor).
  2. Type the 14 lines exactly. Keep every quote mark, bracket, and angle bracket.
  3. Choose File → Save As. Set Save as type to All files, name it money-pop.html, and use UTF-8 encoding so the emojis work.
  4. Double-click money-pop.html to open it in your browser.
  5. Tap the money bag. When the timer reaches zero, press Play Again.

✅ It worked if…

  • You see the four names and a big money bag.
  • Every tap makes the score go up and the bag jump somewhere new.
  • The timer counts down from 15 and the bag turns into a trophy with your score.
  • Play Again starts a fresh round.

Code detective

What each part does

LineWhat it does
1Sets up a web page, makes it fit a phone, and names the browser tab.
2Starts the page, fills the background with sky blue, and centers everything.
3Shows the big game title and the money emoji.
4Gives the instruction and introduces the four crew members and their SR-71.
5Shows the score and the 15-second timer. The spots are named s and t.
6The big money bag button. Clicking it calls the hit() function.
7Play Again reloads the page, which resets the score and timer.
8Starts the JavaScript — the rules of the game.
9Makes variables for the score s, the time t, the bag b, and the timer T.
10move() picks a new random left and top position for the bag.
11hit() adds one coin, updates the screen, and moves the bag.
12Runs move() once at the start, so the bag is not always in the middle.
13Every second, subtract one from the time. At zero, stop the timer, disable the bag, show the trophy and score, and replace the scoreboard with a “time’s up” message.
14Closes the script, body, and page.

🧠 Coding words you just used

  • HTML — the pieces of the page: title, text, buttons.
  • CSS — the styles inside style="…": colors, sizes, positions.
  • Variable — a named box that holds a value, such as s for score.
  • Function — a set of instructions with a name, such as move() and hit().
  • Event — something that happens, such as a click on the money bag.
  • Random — a surprise number, made by Math.random().
  • Timer — code that runs repeatedly, made by setInterval.
  • Condition — an if test, such as “is the time zero?”

Your turn

Make it yours — keep it 14 lines

You can change the game without adding lines. After every change: save (Ctrl + S) and refresh the browser (Ctrl + R).

  1. Change the crew. On line 4, swap the emojis or names for your own favourites.
  2. Make the round longer. If you want 30 seconds, change the 15 on line 5 and the 15 on line 9.
  3. Make the bag bigger. On line 6, change font-size:76px to 100px.
  4. Change the sky. On line 2, replace #bfe8ff with another color name such as #ffe2a8, #d9c7ff, or lightpink.
  5. Change the prize. On line 6, replace 💰 with another emoji: 💎, ⭐, 🍕, or your own.

🐛 If it breaks

  • Blank page: check the quotes, brackets, and angle brackets on the line you changed.
  • Score does not change: check that line 5 says id="s" and line 11 says getElementById("s").
  • Bag does not move: check that line 11 calls move() and that line 12 is there.
  • Timer does not stop: check the t === 0 and clearInterval(T) parts on line 13.
  • Undo with Ctrl + Z and compare with the 14 lines above.

For the grown-up co-pilot

How to run the 20-minute build

Let the child type the code and make the choices. Sit beside them and read the code aloud together. The long first line may need help, but most of the learning is in the small lines that follow.

  • Warm-up (5 min): play the finished game and ask what the score and timer do.
  • Build (10–15 min): type the 14 lines, saving as money-pop.html.
  • Test (5 min): play, find a bug if one appears, and fix it together.
  • Remix (5–10 min): choose one of the “Your turn” changes and test it.

This game intentionally leaves out plane art, moving enemies, collisions, and sound. Those are good next projects, but each one adds many lines. The tiny version proves the core ideas: an event, a variable, a function, randomness, a timer, and a condition.
